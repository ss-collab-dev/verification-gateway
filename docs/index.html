🔐 Verification Gateway

Trust, But Verify — Cryptographic Proof for AI Agent Actions

📝 Intent Compiler

Natural language parsing that converts agent intentions into verifiable actions. "Check market status" becomes a signed, auditable receipt.

🔏 Cryptographic Receipts

Every action generates an Ed25519-signed receipt. Replayable, falsifiable proof of what actually happened.

💾 Persistent Database

SQLite-backed storage with instant verification API. Query receipts by status, timestamp, or verification ID.

🛠️ Developer CLI

Built-in command-line tool for generating receipts, verifying actions, and integrating with your agent stack.

⚡ Zero Dependencies

Pure Python implementation. No external services, no cloud dependencies. Runs entirely on your infrastructure.

🔍 Audit Trail

Complete history of agent actions with cryptographic guarantees. Perfect for compliance and debugging.
