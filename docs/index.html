The Trust Crisis

CVE-2026-41242 • CVSS 9.4

AI agents can currently operate without independent verification, leaving no tamper-evident audit trail.

❌

False Claims

Agents claim they performed actions they didn't actually execute

❌

Misrepresentation

Outcomes of actions are misrepresented or exaggerated

❌

No Verification

No independent way to verify agent claims about world state

❌

No Audit Trail

No tamper-evident record of what actually happened

The Solution

A four-layer architecture that separates intent, execution, verification, and proof 

┌─────────────────────┐
│ Intent Compiler     │ ← Emits falsifiable postconditions
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ Execution Layer     │ ← Runs actions, NO verification rights
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ Verification Gate   │ ← Independent readback of world state
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ Receipt Generator   │ ← Signed, replayable proof (Ed25519)
└─────────────────────┘

1. Intent Compiler

Parses natural language into falsifiable postconditions

2. Execution Layer

Runs actions without verification rights

3. Verification Gate

Independently reads world state to verify claims

4. Receipt Generator

Creates Ed25519 signed, replayable proof

Key Features

✅

Ed25519 Signing

Cryptographically signed receipts that are tamper-evident and verifiable

✅

CLI Tool

Simple `vg` commands for listing, verifying, and querying receipts

✅

Receipt Database

Queryable SQLite database with full history of all verified actions

✅

Schema Validation

JSON Schema ensures receipt structure integrity and consistency

✅

Independent Verification

Gate reads world state directly, not from execution layer

✅

Production Ready

12 core files, comprehensive docs, tested and ready for beta

Quick Start

# 1. Clone the repository
git clone https://github.com/experto-trading/verification-gateway.git
cd verification-gateway

# 2. Install dependencies
pip install -r requirements.txt

# 3. Generate your keys
python receipt_generator.py --generate-keys
# 4. Run the demo
python demo.py

# 5. Check receipts
python vg-cli.py list-receipts
